Never push your changes to the main branch. Always commit your changes to a dev branch, entitled in the format mm-dd-yyyy/agent-name/description-of-changes. (It is ok for you to commit changes to a branch created by another agent, however.) Create a pull request with a message clearly describing the changes you've made.

On the start of every session, always make sure you have the most up-to-date codebase from GitHub. State which branch you are building changes on top of. If it is not the most recent branch, please give a justification for why this is the case. If the main branch is not the most recent branch, please make note of this. If you're not sure which branch to build off of, stop and ask before doing anything else.

If the changes you make diverge from what the most recent paper draft ([https://arxiv.org/pdf/2608.27885](https://arxiv.org/pdf/2608.27885)) says, please note this in `CHANGES_FROM_PAPER.md`.

Provide acknowledgement that you have read and understand this file, and summarize what this file tells you to do.
